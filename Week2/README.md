This lab introduced MongoDB Atlas and demonstrated how to create databases, collections, perform CRUD operations, and use aggregation pipelines.

## Database Creation

Created a database named **peopleDB** and a collection named **people**.

## Insert Operation

Inserted records into the collection using the Insert Document feature.

## Update Operation

Updated existing records by modifying field values.

## Delete Operation

Deleted records from the collection using the Delete option.

## Aggregation Queries

### Match Query

Filtered records based on education and age.

### Average Age Query

Calculated average age grouped by gender.

### Min and Max Age Query

Calculated minimum and maximum ages.

### Salary Statistics Query

Calculated minimum, maximum and average salary values.
